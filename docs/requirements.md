# Requisitos del sistema

## Objetivo

Desarrollar una herramienta en Python para automatizar el procesamiento y análisis de información de proyectos y generar reportes de seguimiento.

## Entrada

El sistema recibirá información de proyectos mediante archivos Excel.

## Datos mínimos

Cada proyecto deberá contener:

- ID del proyecto
- Nombre del proyecto
- Responsable
- Fecha de inicio
- Fecha de finalización
- Presupuesto
- Costo actual
- Avance esperado
- Avance real
- Estado

## Procesamiento

El sistema deberá:

- Leer los datos desde Excel.
- Validar la información.
- Detectar datos faltantes o inconsistentes.
- Calcular indicadores.
- Identificar proyectos con posibles retrasos.
- Identificar desviaciones presupuestarias.
- Clasificar proyectos según su nivel de riesgo.

## Salida

El sistema deberá generar un reporte con:

- Resumen general.
- Indicadores de proyectos.
- Proyectos atrasados.
- Desviaciones presupuestarias.
- Alertas.
- Clasificación de riesgo.
