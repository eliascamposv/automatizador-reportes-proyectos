# Automatizador de Reportes de Proyectos

Herramienta desarrollada en Python para automatizar el procesamiento de información de proyectos y la generación de reportes e indicadores de seguimiento.


## Problema

El seguimiento de proyectos suele involucrar información distribuida en archivos de Excel y procesos repetitivos de consolidación, revisión y elaboración de reportes.

Estos procesos pueden consumir tiempo y generar errores cuando se realizan manualmente.

Este proyecto busca automatizar parte de ese flujo mediante una herramienta desarrollada en Python.

## Objetivos

### Objetivo general

Desarrollar una herramienta que permita procesar información de proyectos y generar reportes de seguimiento de manera automatizada.

### Objetivos específicos

- Leer información estructurada desde archivos Excel.
- Validar y procesar los datos recibidos.
- Calcular indicadores básicos de seguimiento.
- Generar reportes de forma automática.
- Organizar el proyecto siguiendo buenas prácticas de desarrollo.
- Documentar el funcionamiento y la instalación de la herramienta.
